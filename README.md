# Strativ Task Management API

## Overview

A database-backed task management API with user authentication and task management functionality.

## Features

- User registration
- User login
- Password hashing
- Authentication and authorization
- Create tasks
- View tasks
- Update tasks
- Delete tasks
- Input validation
- Structured JSON errors

## API Methods

- GET
- POST
- PATCH
- DELETE

## Project Goals

- Build a REST-style API
- Use a relational database
- Protect user accounts and tasks
- Validate API input
- Add API integration tests
- Document the API
